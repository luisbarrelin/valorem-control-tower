# Valorem Control Tower

Dashboard operacional Corteva / Vylor. Abra o site e use **Atualizar base** para importar o Excel com a aba Report. O arquivo é processado localmente no navegador e não é enviado ao GitHub. Cada navegador mantém sua própria base; não há sincronização entre usuários.

A publicação não inclui a base operacional, imagens de testes ou dados de motoristas e veículos. O HTML é autocontido, com CSS e JavaScript incorporados para facilitar hospedagem estática.

Referência de design: UI UX Pro Max, Next Level Builder (MIT). Consulte THIRD_PARTY_NOTICES.md.
